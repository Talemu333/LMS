# Early Learning Services LMS

Production LMS built with React, Express, Node.js, and MySQL.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Database driver: mysql2

## Local development

### Server
```bash
cd server
npm install
npm run dev
```

### Client
```bash
cd client
npm install
npm run dev
```

Create `server/.env` from `server/.env.example` before starting the API.
